# B/S tech — правила для ИИ-разработчиков

- Сначала читать актуальные файлы, тесты и инструкции конкретного проекта.
- Нельзя передавать секреты, API-токены, персональные данные или приватные файлы внешним моделям; публичный исходный код допустим.
- Поддерживать бесплатные Cloudflare Workers и GitHub Actions, не включать платные ресурсы и API без прямого решения владельца.
- Все изменения в действующем Telegram-боте проверять тестами; не менять webhook, авторизацию и права доступа без отдельного задания.
- Делать изменения в отдельных ветках и Pull Request. Никогда не сливать их в main и не выполнять развёртывание без согласования.
- Не менять действующие GitHub Secrets, Cloudflare или Telegram-токены и не печатать их значения.
- Для бесплатного автоматического ИИ-аудита использовать только `openrouter/free`, без резервного перехода на платные модели.
- Фактически проведённые проверки отделять от запланированных; не утверждать об успешном запуске до получения его результатов.
