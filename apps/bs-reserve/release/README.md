# Сборка B/S Reserve

Пять сборок используют один код из `../source/src`. `config.json` закрепляет Go, restic, контрольные суммы и неизменяемый базовый пакет альфа.1 (из него берутся только коллекторы, примеры и лицензии).

Требования к сборке: Python 3.11+ и Go 1.27.3 на PATH. Пользователю готовой программы они не нужны.

```sh
python apps/bs-reserve/release/check_native.py linux_amd64 --race
python apps/bs-reserve/release/build.py
python apps/bs-reserve/release/publish.py
```

`check_native.py` требует совпадения ОС/архитектуры с целью. Он запускает Go-тесты, go vet и готовую программу с вымышленными данными. `build.py` проверяет хеш базового пакета и каждой версии restic, собирает бинарные файлы, создаёт архивы с правами выполнения, внутренние и внешние SHA-256 и манифест версии. Рабочая Data и символические ссылки в поставку не допускаются. `publish.py` заполняет страницу загрузок реальными суммами построенных файлов.

Workflow `.github/workflows/reserve-platforms.yml` проверяет Linux x64/ARM64, macOS Intel/Apple Silicon и Windows x64 на соответствующих GitHub runners. Сборка и запись готовых архивов на ветку публикации идут только после успешных проверок всех целей. main обновляется отдельно после просмотра результата.

macOS собирается как `.app`, без Developer ID и нотариализации Apple. Linux распространяется в tar.gz. Встроенное хранение ключа и расписание альфа.2 реализованы только для Windows; macOS/Linux используют ручной пароль и ручное шифрованное копирование. Импорт из Inbox при открытой программе поддерживают все платформы.
