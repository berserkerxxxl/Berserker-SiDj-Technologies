Три шага для начала

  1. Полностью распакуй ZIP в отдельную папку.
  2. В Проводнике дважды нажми B_S_Reserve.exe. Интерфейс откроется в браузере.
  3. Добавь официальный ZIP ChatGPT или сначала проверь программу на вымышленных примерах.

Установка Python и Node.js не требуется. Оставь папку bin рядом с EXE.

Сначала проверь восстановление

На странице «Резервные копии» создай отдельный репозиторий, сохрани копию, затем восстанови её в новую пустую папку. Сохрани аварийный пароль отдельно от ПК.

Рабочая папка Data открытая. Зашифрованы репозитории restic. Выпуск ещё не проверялся нативно на Windows и с твоим аккаунтом ChatGPT.

Готовые экспортёры

Копии для установки лежат в collectors. В вариантах B/S Reserve заблокированы запросы изменения/удаления. Для Firefox: about:debugging#/runtime/this-firefox → «Загрузить временное дополнение» → collectors/chatgpt-export-safe/firefox/manifest.json.

В thekester включи Raw JSON data, All branches, файлы и SHA-256. После перезапуска Firefox временное дополнение нужно загрузить снова.
