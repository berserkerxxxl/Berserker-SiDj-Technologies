## Запуск Windows

1. Полностью распакуйте ZIP в отдельную папку, например D:\BS_Reserve. Не запускайте EXE внутри ZIP.
2. Запустите **B_S_Reserve.exe**. Python, Node.js и Go для работы не нужны.
3. Откроется русский интерфейс в браузере по локальному адресу. Программа работает только на 127.0.0.1.
4. Сохраните рабочую папку целиком: **bin/restic.exe** необходим для шифрования и восстановления. При запуске создаётся папка **Data**.
5. Чтобы остановить программу, нажмите **Завершить работу** в панели слева. Закрытие вкладки оставляет программу работающей.

Первый выпуск не подписан сертификатом разработчика. Проверить байты поставки можно по **SHA256SUMS.txt**. Автоматического установщика и запуска с правами администратора нет.

## Проверка на примерах

На странице **Получить экспорт** нажмите **Проверить на вымышленных примерах**. Будут добавлены только синтетические разговоры и тестовая память из **examples**.

Пример содержит официальную структуру conversations.json, ZIP с raw.json, вложением и манифестом SHA-256, обновление уже сохранённого разговора и JSON вымышленной памяти. Это тестовые данные, а не копия вашего аккаунта.

## Получение настоящих данных

Официальный путь: ChatGPT → Настройки → Управление данными → Экспорт данных. Подготовка может занять до 7 дней; ссылка действует 24 часа. Скачивать нужно при входе в тот же аккаунт. Условия проверены по официальной справке 28.10.2026.

Добавьте ZIP кнопкой **Добавить файлы** или перетащите его на главный экран. Можно добавлять несколько файлов по очереди.

Принимаются отдельные JSON и части многочастной выгрузки, ZIP thekester с включённым Raw JSON data, JSON переписок и памяти ChatGPT Helper, обычные документы, изображения, архивы и исходники. Поле **Разработка целой папкой** сохраняет выбранную папку с относительными путями.

Для папки копируются и обычные файлы .git. Символические ссылки пропускаются с предупреждением. Специализированный экспорт работающих баз, Git LFS и подмодулей нужно проверять отдельно. Папка разработки должна быть отдельно от Data.

Программа не входит в ChatGPT и не принимает его пароли или токены. Новая выгрузка аккаунта получается отдельно. Истёкшие, удалённые или отсутствующие в источнике данные не реконструируются как подлинники.

В **third-party** — неизменённые исходники выбранных проектов с лицензиями и закреплёнными коммитами. Для установки используйте модифицированные копии из **collectors**:

В копиях B/S Reserve добавлена блокировка сетевых запросов кроме GET/HEAD. В thekester дополнительно защищён authFetch, включая путь Firefox, и выключены флажки автоматического удаления. Пункты удаления, оставшиеся в интерфейсе исходного проекта, не предназначены для использования.

### Firefox

Откройте **about:debugging#/runtime/this-firefox** → **Загрузить временное дополнение** → выберите manifest.json из папки Firefox выше. Временную установку нужно повторять после перезапуска браузера. Сборка рассчитана на Firefox 140+.

### Chrome / Edge

Откройте **chrome://extensions** либо **edge://extensions**, включите режим разработчика, выберите **Загрузить распакованное расширение** и нужную папку. D1DX оставлен в формате Chrome.

Откройте ChatGPT и выполните экспорт. Для thekester включите **Raw JSON data**, **All branches**, **Save images**, **Save attachments and generated files**, **SHA-256 checksums**. Для первого экспорта нужен полный набор; инкрементальный режим имеет смысл после проверки первой копии.

Дополнительный доступ к внешним сайтам для соответствующих удалённых ресурсов остаётся отдельным разрешением расширения.

**Ограничение:** исходники и блокировки проверены локально, но работа расширений с вашим аккаунтом не проверялась. Внутренние интерфейсы ChatGPT могут меняться. Сравнивайте фактическую полноту файлов с официальным экспортом. Блокировка методов может потребовать пересмотра, если законный экспорт начнёт требовать POST.

## macOS и Linux

Скачайте сборку для своей архитектуры. В macOS откройте «Об этом Mac»: Apple M-серии — **Apple Silicon (arm64)**; процессор Intel — **Intel (x64)**. В Linux `uname -m` обычно показывает `x86_64` для x64 или `aarch64` для ARM64. 32-битные системы в этом выпуске не поддерживаются.

### macOS 13 Ventura и новее

1. Полностью распакуйте ZIP. Откройте **B_S_Reserve.app**. Можно перенести приложение в Applications; документацию и коллекторы сохраните из папки выпуска отдельно.
2. Интерфейс откроется в браузере. Дополнительная установка Go, Python, Node.js и restic не нужна.
3. Приложение не имеет подписи Developer ID и нотариализации Apple. При предупреждении неизвестного разработчика проверьте источник и SHA-256; порядок открытия конкретного приложения описан Apple: https://support.apple.com/102445. Глобально отключать Gatekeeper не требуется. Сообщение о повреждении или вредоносном ПО не обходите; сообщите о нём разработчикам.
4. Рабочие данные: **~/Library/Application Support/BerserkerSiDj/Reserve/Data**. Обновление или перемещение .app не заменяет эту папку.
5. Для командной строки: `./B_S_Reserve.app/Contents/MacOS/B_S_Reserve --no-browser`. Комплектный restic лежит в `B_S_Reserve.app/Contents/MacOS/bin/restic`.

### Linux x64 и ARM64

1. Распакуйте архив **tar.gz** целиком, сохранив права выполнения: `tar -xzf BS_Reserve_..._linux_x64.tar.gz` (имя зависит от архитектуры).
2. В распакованной папке выполните `./START.sh` или `./B_S_Reserve`. Системные права администратора не нужны. При графическом сеансе используется xdg-open; если браузер не открылся, скопируйте напечатанный адрес `http://127.0.0.1:...` в браузер.
3. Рабочие данные: **$XDG_DATA_HOME/berserker-sidj/reserve/Data**, по умолчанию **~/.local/share/berserker-sidj/reserve/Data**. Путь показан в интерфейсе. Папку bin оставьте рядом с исполняемым файлом.
4. Для работы без автоматического открытия браузера: `./B_S_Reserve --no-browser`. Интерфейс слушает только 127.0.0.1. Внешний сетевой интерфейс программа не публикует.
5. Бинарные файлы Linux собраны без cgo и не требуют установленной glibc. Рекомендуется современный 64-битный дистрибутив; для графического интерфейса нужен браузер. Это не выпуск для Android, iOS или WSL1.

**Ограничение альфы macOS/Linux:** импорт, поиск, версии, память, шифрование, проверка и восстановление доступны. Пароль репозитория вводится перед каждой операцией. Связка ключей macOS и хранилище секретов Linux пока не подключены; запоминание пароля, встроенное расписание и автоматическое шифрование после импорта отключены. Автоматический приём готовых файлов из Inbox работает, пока программа запущена. Шифрованную копию запускайте вручную.

Для отдельного каталога на любой ОС используйте `--data "ПУТЬ"`. Для переноса существующего каталога сначала завершите программу, скопируйте **всю Data**, а затем укажите новую копию через --data. Для restic-репозитория нужен весь репозиторий и аварийный пароль. Ключ DPAPI Windows на другую ОС не переносится; открытые форматы Vault и парольные снимки restic независимы от ОС.

## Структура данных

- **Data/Vault/objects** — оригинальные байты по SHA-256, включая исходные ZIP;
- **Data/Vault/catalog.json** — источники, файлы, разговоры и версии;
- **Data/Vault/catalog.previous.json** — предыдущая запись каталога;
- **Data/Vault/conversations** — JSON со всей полученной структурой и Markdown всех доступных узлов;
- **Data/Vault/knowledge** — снимки памяти и инструкций;
- **Data/Inbox** — приём завершённых файлов;
- **Data/Outbox** — незашифрованные пакеты переноса;
- **Data/logs/operations.jsonl** — журнал;
- **Data/config** — настройки и, если разрешено пользователем, защищённые Windows ключи.

Каталог первой версии — документированный JSON. SQLite и специализированные адаптеры локальных оболочек остаются следующим этапом. Для чтения Markdown и JSON доступ к OpenAI не нужен.

Повторный идентичный источник пропускается. Изменённый разговор получает новую версию. Более старый экспорт не заменяет текущую версию с более поздней датой обновления. Старые версии не удаляются.

Оригинальные сжатые ZIP могут занимать дополнительное место. Локальная дедупликация не отменяет необходимости снова скачивать полный серверный экспорт.

## Зашифрованная копия

1. Откройте **Резервные копии**.
2. Укажите новую отдельную папку, например E:\BS_Reserve_Backup. Она не должна пересекаться с рабочей папкой Vault.
3. Задайте пароль не менее 12 символов и повторите его.
4. Нажмите **Создать репозиторий**, затем **Сохранить копию**.
5. Сохраните аварийный пароль отдельно от этого ПК.

Движок **restic 0.19.1** входит в комплект. Его SHA-256 сверялся с опубликованными контрольными суммами; приложение проверяет хеш бинарного файла перед первым использованием.

Рабочие файлы в **Data/Vault, Inbox и Outbox не зашифрованы приложением**. Шифруются репозитории restic. Для защиты всех исходников используйте зашифрованный диск и права доступа ОС.

Базовая проверка структуры выполняется после копирования. Кнопка **Прочитать и проверить все данные** проверяет содержимое всех блоков. Практическую пригодность копии подтверждает пробное восстановление.

Держите независимые копии на разных носителях; хотя бы одну отключайте между обновлениями. Выпуск управляет одним выбранным репозиторием за операцию. Для другого носителя укажите другую папку и создайте отдельную копию. Автоматической ротации носителей и удаления старых снимков нет.

## Автоматизация Windows

**Подбирать завершённые файлы из Inbox** — при работающей программе папка проверяется каждые 20 секунд. Файлы моложе 10 секунд, временные загрузки и каталоги пропускаются. Повторные файлы не создают повторных логических копий.

**После импорта создавать зашифрованную копию** — требует включённого параметра, доступного носителя и сохранённого на этом ПК ключа. При ошибке копирования импортированные данные остаются в рабочей папке.

Флажок **Запомнить ключ на этом ПК** использует DPAPI для текущего пользователя Windows. Пароль не записывается в настройки или журнал; restic получает его в окружении дочернего процесса. DPAPI не заменяет аварийный пароль.

Кнопка расписания создаёт задачу текущего пользователя: ежедневно в **19:00 по времени Windows** и при входе. Запускается EXE с параметром --run-once; нужны доступ к папкам и подключённый носитель. Повышение прав не запрашивается. Если программа уже работает, запрос передаётся её локальному интерфейсу. При занятом ядре задача получает ошибку, а выполняемая операция продолжается.

Даты журнала отображаются по Москве. Расписание следует часовому поясу Windows. После перемещения EXE или Data создайте задачу снова; старую задачу с префиксом BS_Reserve_ для прежнего пути можно отключить в Планировщике.

Новый серверный экспорт ChatGPT по-прежнему нужно получать отдельно. Ежедневная копия старого ZIP не содержит новых чатов.

## Восстановление

Укажите репозиторий и пароль, получите список снимков, выберите снимок и **новую пустую папку**. После восстановления программа проверит оригиналы, JSON/Markdown и записи памяти.

Аварийно, без B/S Reserve и без OpenAI:

    bin\restic.exe -r "E:\BS_Reserve_Backup" snapshots
    bin\restic.exe -r "E:\BS_Reserve_Backup" restore ID_СНИМКА --target "D:\Reserve_Restore"

Пароль введите по запросу restic. Не включайте его в команду.

В восстановлении появится Vault. Его README_RESTORE_RU.txt объясняет формат и восстановление исходных имён файлов. Для открытия восстановленного каталога через программу используйте отдельную копию EXE с параметром --data "D:\Reserve_Restore" после проверки.

## Перенос знаний

Кнопка **Пакет переноса ZIP** создаёт **незашифрованный** пакет в Data/Outbox:

- **index.html** — автономный просмотрщик с поиском по тексту;
- **Vault** — оригиналы и все версии;
- **files** — оригинальные файлы с читаемыми именами;
- **START_HERE_RU.txt** — инструкция.

Для нового ChatGPT загружайте выбранные разговоры, инструкции и документы. Старая боковая панель, отдельные чаты и внутренняя память автоматически не воссоздаются. Для «СиДжи Offline» доступны JSON/Markdown и документы; прямой импорт в конкретную оболочку этим выпуском не реализован.

## Проверки и границы выпуска

Протокол — **TEST_REPORT_RU.md**.

Общее ядро проверяет импорт, ветви и версии, дедупликацию, файлы, хеши, опасные пути ZIP, память, локальную HTTP-границу, поиск, перенос, шифрование и восстановление настоящим restic. Все платформы собираются из одного исходного кода.

При публикации выполняются автоматические проверки на Linux x64/ARM64, macOS Intel/Apple Silicon и Windows x64; протокол и ссылка на запуск — TEST_REPORT_RU.md. Автоматические проверки не заменяют запуск на пользовательском компьютере. **Интерактивный первый запуск через Finder/Gatekeeper, регистрация задачи Планировщика Windows и экспорт из живого аккаунта ChatGPT требуют пользовательского тестирования.**

Лимиты: входной файл до 2 ГиБ; распакованный ZIP/папка до 8 ГиБ и 100000 файлов; отдельный разбираемый JSON до 256 МиБ. Большой JSON сохраняется исходником с предупреждением; используйте разбиение. Неизвестные JSON сохраняются, но не объявляются распознанными переписками.
