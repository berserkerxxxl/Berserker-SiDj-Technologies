Зашифрованный репозиторий

Выбери отдельную папку, желательно на другом носителе. restic сохраняет снимки и повторно использует одинаковые блоки.

Сохрани аварийный пароль отдельно. Он нужен для восстановления на другом компьютере.
macOS и Linux: вводи пароль перед каждой операцией с репозиторием. В этой альфе ключ не сохраняется, встроенное расписание и автоматическое шифрование недоступны. Автоматический приём Inbox работает при открытой программе.

Независимость от аккаунта

В комплекте есть движок restic и инструкция аварийного восстановления. Для чтения восстановленных JSON и Markdown вход в OpenAI не требуется.

Автоматическое удаление старых снимков в этом выпуске отсутствует.

Официальная выгрузка ChatGPT

1Запроси экспорт

ChatGPT → Настройки → Управление данными → Экспорт данных. Подготовка может занять до 7 дней.

2Скачай готовый ZIP

Ссылка действует 24 часа. Используй тот же аккаунт, который запросил выгрузку.

3Добавь файл в B/S Reserve

Перетащи его на главный экран или скопируй в Inbox. Отдельно добавь память, инструкции и важные разработки.

Официальная инструкция OpenAI ↗

Готовые экспортёры в комплекте

ChatGPT Markdown Export / thekester
Firefox и Chromium. Папка collectors/chatgpt-export-safe.

ChatGPT Helper / D1DX
Chrome. Папка collectors/chatgpt-helper-safe; интересен отдельным экспортом памяти.

В копиях для B/S Reserve заблокированы запросы DELETE, PATCH и PUT. Настрой экспорт с Raw JSON, файлами, всеми ветвями и SHA-256. Возможности зависят от интерфейсов ChatGPT.

Для Firefox используется временная установка через about:debugging. После перезапуска браузера расширение потребуется загрузить снова. Подробная инструкция — START_HERE_RU.html в папке выпуска.

Работа с твоим аккаунтом ещё не проверена. Программа не принимает токены и пароли ChatGPT.
