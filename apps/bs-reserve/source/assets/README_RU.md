# Эмблема B/S Reserve для Windows

`bs-logo-original.png` — исходная прозрачная эмблема, предоставленная для проекта. `bs-reserve.ico` содержит варианты 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 пикселей. Убраны только пустые прозрачные поля; форма и цвета эмблемы сохранены. Эмблема вписана по центру квадратного прозрачного поля.

`../src/rsrc_windows_amd64.syso` — готовый объект ресурсов COFF для Windows x64. Go автоматически включает его в Windows EXE. Для обычной сборки дополнительные инструменты не нужны. Файлы исходной эмблемы и ICO не требуются рядом с работающим EXE.

Для обновления ресурса из уже подготовленного ICO выполните из корня репозитория:

```sh
go run github.com/akavel/rsrc@v0.10.2 -ico apps/bs-reserve/source/assets/bs-reserve.ico -arch amd64 -o apps/bs-reserve/source/src/rsrc_windows_amd64.syso
```

Используется точная версия MIT-инструмента [akavel/rsrc](https://github.com/akavel/rsrc/tree/v0.10.2); контрольная сумма Go-модуля указана в `ICON_MANIFEST.json`. Инструмент генерации не является зависимостью работающей программы.

При нативной проверке Windows считываются RT_GROUP_ICON и все RT_ICON из готового EXE, байты сравниваются с ICO, а ExtractIconExW проверяет извлечение большого и маленького значков средствами оболочки Windows.
