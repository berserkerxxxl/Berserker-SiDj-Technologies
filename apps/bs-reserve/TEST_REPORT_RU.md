# Проверка B/S Reserve 0.1.0-alpha.1

Билд: **20261028.2**. Дата: **28 октября 2026 года**.

Проверки выполнялись на вымышленных данных. Доступ к аккаунту пользователя и его содержимому не использовался.

## Результат

**12 тестов ядра прошли**, включая запуск с детектором гонок данных. Реальный цикл restic: создание репозитория → шифрование → список снимков → полное чтение → восстановление в новую папку → сверка хешей. Неверный пароль и намеренное повреждение зашифрованного блока выявлены.

## Интерфейс

В headless Chromium на Linux выполнен сценарий:

1. Первый запуск с пустым каталогом.
2. Импорт трёх вымышленных источников: один разговор, две версии, одна запись памяти.
3. Поиск по тексту и открытие переписки.
4. Сохранение отдельной инструкции.
5. Проверка SHA-256 через локальный интерфейс.
6. Создание зашифрованного репозитория и снимка.
7. Получение списка, полное чтение и проверенное восстановление.
8. Формирование ZIP для переноса и открытие автономного HTML без сервера.
9. Поиск и чтение в автономном архиве.
10. Проверка ширины интерфейса на 1440 и 390 пикселях; горизонтального переполнения нет.

Ошибок JavaScript в этом сценарии не обнаружено. Внешних сетевых запросов от интерфейса B/S Reserve не обнаружено. Скриншоты использовались только для внутренней визуальной проверки и не включены в поставку.

- Windows EXE собран для amd64 без внешнего интерпретатора.

## Что ещё не проверено

**Нативный запуск Windows 11, защита/разблокирование DPAPI, фактическая регистрация задачи Планировщика и работа расширений в живом аккаунте ChatGPT не выполнялись.**

Архивный цикл проверен на Linux настоящим restic. Исходники Windows-ветвей скомпилированы и прошли статическую проверку, однако это не заменяет испытание на целевом компьютере.

Скорость и полнота обработки многолетнего реального аккаунта, текущий формат улучшенной памяти и большие выгрузки около пределов прототипа требуют проверки на фактических источниках. Первый выпуск не объявляется полным резервированием аккаунта.
