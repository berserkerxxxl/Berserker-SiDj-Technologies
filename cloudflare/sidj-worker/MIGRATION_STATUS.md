## Продолжение после входа

1. Проверить тариф Workers Free и подключить только нужный GitHub-репозиторий.
2. Развернуть `bs-tech-sidj` из `cloudflare/sidj-worker` по README_RU.md.
3. Через интерфейс Cloudflare ввести `SIDJ_TELEGRAM_BOT_TOKEN`, `SIDJ_TELEGRAM_CHAT_ID`, отдельный `SIDJ_ADMIN_TOKEN`; указать `SIDJ_PUBLIC_URL`.
4. Если токен был раскрыт ранее, подготовить оба интерфейса секретов, провести смену через BotFather и синхронизировать Cloudflare/GitHub. Не отзывать токен заранее, пока новая конфигурация не готова.
5. Проверить `/setup`, дождаться окончания старого job опроса и активировать webhook без сброса очереди.
6. Выполнить настоящие команды и нажатия, получить маленькое вложение/ZIP/ссылку, проверить SHA-256 и фактическую скорость/CPU/ошибки Cloudflare.
7. Только после успешной проверки отключить `sidj-telegram-commands.yml`. `sidj-telegram-notify.yml` оставить включённым.
