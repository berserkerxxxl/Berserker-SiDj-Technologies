## Исправления совместимости

Служебный HTTP-клиент открыто указывает имя проекта и URL исходников: стандартный Python-urllib получал Cloudflare 403 / 1010. Идентифицированный клиент получает ответ Worker без имитации браузера. Исходящие запросы Worker используют поддерживаемый redirect: manual с явным отказом от 3xx: прежний redirect: error не поддерживается workerd. Это проверяется настоящим runtime, а не только подменой fetch в Node.
