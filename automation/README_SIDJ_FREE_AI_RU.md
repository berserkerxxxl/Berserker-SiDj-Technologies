# B/S tech — бесплатный ИИ-разработчик для SiDj

Это экспериментальный **бесплатный** помощник с ручным одобрением. Он один раз в неделю (вторник, 07:17 МСК) или вручную предлагает **одно небольшое улучшение** для `cloudflare/sidj-worker/src/index.js`. Изменения проходят проверки, после чего открывается **черновик Pull Request**. Агент не может сливать PR или запускать развёртывание. Уже открытый PR с префиксом `ai/sidj-free-` блокирует новые предложения до рассмотрения.

## Включение (один раз, владельцем)

1. Создать **бесплатный** ключ на https://openrouter.ai/settings/keys — без покупки кредитов. Приоритетная бесплатная модель: `recursive/flint-v1.0:free`; при ошибке провайдера резервная — `nvidia/nemotron-3-ultra-550b-a55b:free`. Обе с ценой модели `$0`; лимиты и доступность зависят от OpenRouter.
2. Добавить ключ только в GitHub: https://github.com/berserkerxxxl/Berserker-SiDj-Technologies/settings/secrets/actions/new ; имя **`OPENROUTER_API_KEY`**. Ключ не присылать в чат, не вставлять в файл репозитория.
3. В https://github.com/berserkerxxxl/Berserker-SiDj-Technologies/settings/actions в разделе **Workflow permissions** разрешить GitHub Actions создавать Pull Requests, если это запрещено по умолчанию. Учесть, что с этим связано право на создание черновиков через `GITHUB_TOKEN`; прав на авто-слияние этому workflow не даётся.
4. После объединения установочного PR в `main` перейти в Actions → **B/S tech - free AI improvement proposals** → **Run workflow**.
5. Просмотреть summary запуска. При безопасном изменении появится **draft PR**, где можно изучить diff. Если ключ отсутствует, запуск ничего не меняет. Если модель отклонилась от правил или тесты не прошли, PR не создаётся.

## Защита от платных расходов и произвольных изменений

- Один HTTP-запрос в OpenRouter за запуск, с явно ограниченным списком из **двух моделей только с суффиксом `:free`**. OpenRouter может выбрать резервную лишь при ошибке основной; платные модели исключены. При HTTP 429/402 после попыток бесплатного маршрута работа останавливается без повторов со стороны скрипта.
- Передаётся только публичный `src/index.js`, никаких GitHub, Telegram или Cloudflare секретов. Запрос делается через HTTPS с запретом перенаправлений.
- Модель должна предложить одну точную замену небольшого фрагмента **только в `src/index.js`**. Импорты, токены, авторизация и webhook вне области правок. Скрипт отклоняет изменения иных файлов, неоднозначные замены и слишком большие патчи.
- Тесты и анализ синтаксиса выполняются **без секретов**; GitHub-токен передаётся лишь на финальном этапе открытия PR. Выкатка в Cloudflare не предусмотрена.
- Бесплатные модели иногда ошибаются: тесты не заменяют ручного ревью. Патч можно отклонить и закрыть PR.
- GitHub Actions для стандартных хостинговых runner в публичных репозиториях бесплатен. Не включать платные runner и сервисы.

## Важные ограничения

- Этот workflow **не делает публикацию сам** и не работает до объединения установочного PR, добавления секрета и разрешения на создание PR.
- С июня 2026 года для Pull Request, созданного через `GITHUB_TOKEN`, GitHub может поставить CI в состояние **ожидания одобрения**: владелец нажимает **Approve workflows to run**. Скрипт также выполняет проверки **до** открытия PR, внутри AI-workflow. При ручных дополнительных правках тесты необходимо повторить.
- После второго запуска 30.10.2026 (HTTP 404: Qwen3 Coder `:free` отсутствует в текущем API-каталоге) зафиксирован контролируемый список: **Flint (free)** и **Nemotron 3 Ultra (free)**. Используется JSON-режим вывода, лимит 3000 токенов. Если обе недоступны, агент завершится без PR. Отсутствие качественного предложения также не приведёт к изменениям кода.
- Включать автоисправления других файлов или подключать ИИ к приватным репозиториям без отдельного согласования нельзя.


## Уведомления об ИИ в Telegram

Дополнительный workflow **B/S tech - AI proposals to Telegram** автоматически запускается после завершения еженедельного или ручного **B/S tech - free AI improvement proposals** (только ветка main и собственный репозиторий).

- Если ИИ создал черновик Pull Request, бот **@BS_SiDj_bot** присылает в личный чат: номер PR, конкретное предложение, объяснение, название бесплатной модели и кнопку «Посмотреть предложение».
- Если PR не создан или аудит завершился ошибкой, бот сообщает об этом и даёт ссылку на журнал запуска.
- Одно уведомление соответствует одному завершённому аудиту. Автоматическое объединение PR или публикация Worker не выполняются.
- Telegram-токен и ID личного чата читаются только отдельным workflow из ранее настроенных GitHub Secrets. Вызов ИИ этих секретов не получает. Код из PR не исполняется в уведомляющем workflow.
- Для **однократной проверки канала** в GitHub открой Actions → «B/S tech - AI proposals to Telegram» → Run workflow → main. Он покажет последнее открытое предложение ИИ (если есть), без дополнительного запроса к OpenRouter.
- Уже прошедшие аудиты до установки этой функции автоматически не пересылаются; ручной тест позволяет отправить в чат последнее открытое предложение.


## Общий бесплатный аудит программ B/S tech

Отдельный workflow **B/S tech - portfolio AI review (read-only)** запускается по воскресеньям в **08:41 МСК** или вручную. Он отправляет в личный Telegram отдельное сообщение для каждого проекта, где указывает название программы, реально просмотренный файл/часть файла, вывод ИИ и рекомендацию:

- B/S SiDj — Telegram-бот Cloudflare;
- B/S SiDj — ИИ-разработчик OpenRouter (в том числе проверяет собственные исходники);
- B/S Reserve — открытые исходники Go;
- B/S Excel Toolkit — HTML/JavaScript;
- B/S tech-Limits AI — Tampermonkey;
- сайт B/S tech — HTML/JavaScript;
- B/S Codex Installer — пока без ИИ-проверки: есть EXE, но нет исходников.

**Границы и безопасность:** каждая проверка делает не больше **одного бесплатного запроса** в OpenRouter, без переключения на платные модели и без повторов при ошибке. У больших программ анализируется ограниченный фрагмент исходника (до 18 000 символов за запуск), фрагменты/файлы чередуются по неделям; это не полный аудит. Источник — только публичные файлы из явно разрешённого списка. ИИ не выполняет код, не получает секреты Telegram, не создаёт PR в обзорном режиме и не изменяет готовые программы. Для исправлений по результатам нужно отдельное ревью и тестирование. Действующий бот сохраняет свой отдельный ограниченный workflow по созданию PR.

[Запустить общий обзор вручную](https://github.com/berserkerxxxl/Berserker-SiDj-Technologies/actions/workflows/sidj-portfolio-ai-review.yml). Он отправит до семи отдельных уведомлений в личный Telegram (по одному на проект, включая сообщение об отсутствии исходников Codex Installer). Доступность бесплатных моделей зависит от провайдера; при сбоях придёт отчёт об ошибке без платных запросов.
